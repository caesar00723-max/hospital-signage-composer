병원 간판 이미지 합성

크로마키(마젠타) 패널이 포함된 생성 이미지에 한글 병원명을 자동 합성합니다.

⚙️ 저장소 연결 설정 (최초 1회)

토큰은 이 브라우저에만 저장되며(localStorage), 저장소나 서버 어디에도 전송·기록되지 않습니다. GitHub → Settings → Developer settings → Fine-grained tokens 에서 이 저장소 하나만 선택하고 Contents: Read/Write, Actions: Read/Write 권한만 부여해서 발급하세요.

0을 입력하면 두께감(측면·그림자) 표현을 끕니다.
